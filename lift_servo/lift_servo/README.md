# lift_servo STM32 串口控制固件

目标平台：STM32F103C8、PlatformIO、Arduino STM32 Core。固件通过 USART1
接收行文本命令，并用 `PUL + DIR` 控制 step-servo drive。上电默认禁止输出，
发生驱动器报警或执行急停后锁存，必须在报警消失后执行 `CLEAR` 才能恢复。

## 引脚与接线

| STM32 | 方向 | 电平转换 | 驱动器 | 程序用途 |
|---|---:|---|---|---|
| PA0 | 输出 | A0 -> B0 | PUL+ | 脉冲 |
| PA1 | 输出 | A1 -> B1 | DIR+ | 方向 |
| PA2 | 输出 | A2 -> B2 | ENA+ | 使能/脱机 |
| PA3 | 输入 | A3 <- B3 | PEND 输出 | 到位反馈 |
| PA4 | 输入 | A4 <- B4 | ALM 输出 | 报警反馈 |
| PA9 / USART1_TX | 输出 | — | HW-587B RX | STM32 发数据 |
| PA10 / USART1_RX | 输入 | — | HW-587B TX | STM32 收数据 |
| GND | — | 共地 | GND | 逻辑参考地 |

> UART 必须交叉连接：PA9(TX) 接模块 RX，PA10(RX) 接模块 TX。题目中两个都写成
> RX 无法实现双向通信。

在上电前必须根据**实际驱动器手册**完成下列检查：

1. PUL、DIR、ENA 是成对光耦输入，不能只接 `+` 而让 `-` 悬空。当前程序按“共阴”
   假设驱动 `+`，对应的 `PUL- / DIR- / ENA-` 应按手册接逻辑地。若采用常见的
   “共阳”接法，应将 `+` 固定到 +5 V、由控制器驱动 `-`，并相应修改程序极性。
2. PEND 和 ALM 是成对的光耦/开集电极输出，不是普通 5 V 推挽输出。`PEND+`、
   `PEND-`、`ALM+`、`ALM-` 应按手册组成带限流/上拉的回路，再送入电平转换器；
   不要只凭端子名把 `PEND+ / ALM+` 直接当 TTL 信号。
3. 电平转换模块必须允许 B 侧 5 V 输入安全转换至 A 侧 3.3 V。PA3/PA4 不耐受
   任意 5 V 直灌。电机 24 V 电源绝不能接到 STM32、电平转换器或 UART 引脚。
4. ENA 在很多驱动器中实际是“脱机/释放电机”信号。默认配置
   `kEnaSignalDisablesDrive = true`；必须根据驱动器手册确认。
5. `FWD/REV` 只代表 DIR 电平。安装前先脱开负载低速点动；如果机械方向相反，修改
   `kForwardDirectionLevel`，不要在上位机和固件两处同时反转。

所有电气极性和安全时序集中在 `include/app_config.h`，不要分散修改。

## 串口参数与回复

- USART1：115200 baud、8 数据位、无校验、1 停止位（8N1）
- 每条命令以 `\n` 或 `\r\n` 结尾；不区分大小写
- 成功：`OK <COMMAND>`
- 失败：`ERR <错误码> <说明>`
- 查询：一行以 `STATUS` 开头的键值列表

## 命令

| 命令 | 说明 |
|---|---|
| `PING` / `KEEPALIVE` | 通信测试；同时刷新看门狗 |
| `STATUS` | 查询状态、方向、报警、到位、速度和剩余脉冲 |
| `ENABLE` | 允许驱动器保持转矩，不产生脉冲 |
| `DISABLE` | 立即停止脉冲并使驱动器脱机 |
| `RUN FWD [pps]` | 按正方向连续运行，可选脉冲/秒 |
| `RUN REV [pps]` | 按反方向连续运行 |
| `MOVE FWD <脉冲数> [pps]` | 正方向运行指定脉冲数 |
| `MOVE REV <脉冲数> [pps]` | 反方向运行指定脉冲数 |
| `SPEED <pps>` | 设默认速度，范围 1–20000 pps |
| `STOP` | 立即停止发脉冲，保持驱动器使能/抱持 |
| `ESTOP` | 立即停止、脱机并锁存急停状态 |
| `CLEAR` | ALM 已解除时清除 FAULT/ESTOP；清除后仍为禁止状态 |
| `WATCHDOG <ms>` | 0 关闭；1–60000 ms 内无有效命令时停止脉冲并保持使能 |
| `HELP` | 输出命令摘要 |

示例：

```text
STATUS
MOVE FWD 2000 500
STATUS
RUN REV 800
KEEPALIVE
STOP
DISABLE
```

新 `RUN` 或 `MOVE` 会原子地替换正在执行的运动：停止脉冲输出；若驱动器尚未使能，
则先解除脱机并等待 200 ms；随后设置方向并等待方向建立时间，最后才发脉冲。不会同时
存在两个运动任务。有限位移完成后保持使能。ALM 在任何
状态下都有最高优先级，会停止脉冲、脱机并进入 `FAULT`。

## 烧录前验证

1. 不接 24 V 电机电源，只给控制板供电，检查 PA0/PA1/PA2 的电平和串口回复。
2. 接驱动器逻辑侧但不接机械负载，以 `MOVE FWD 10 10` 和 `MOVE REV 10 10` 验证
   脉冲、方向、ENA、PEND、ALM 的有效电平。
3. 确认方向后再接负载，并从低速、少量脉冲开始。
4. 升降机构必须另装上下硬限位和硬件急停。本工程没有限位输入，单靠 PEND/ALM
   不能防止撞顶、坠落或超行程。

构建：

```bash
pio run
```

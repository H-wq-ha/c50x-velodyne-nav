## 文件放置

- `src/`：ROS 2 源码、配置、启动文件和包内测试。
- `scripts/`：日常操作脚本。
- `tools/`：诊断、分析、可视化与独立遥控工具。
- `tool/`：标定系统和依赖源码，保留现有内部路径。
- `docs/`：长期维护的架构、操作和专题说明；新增专题在本页登记。
- `maps/`：用户自己的地图及完整地图包；当前只保留 `.gitkeep`。
- `output/`、`tool/runs/`：运行时生成的输出与采集轮次，不作为程序源码。

文档应区分源码行为、历史记录和本次实测。涉及默认值或启动入口的调整，同步更新 README、对应专题及项目记忆；参数数值以源码配置和 TF 专题为准。
